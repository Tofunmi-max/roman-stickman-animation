# Roman Stickman History — Episode 01

A vertical 9:16 Remotion prototype about the traditional story of the Roman monarchy's overthrow and the rise of the Republic.

## Run

- pm install
- pm run dev to open Remotion Studio
- pm run render to render out/roman-republic-rise.mp4

Composition: RomanRepublicRise · 1080×1920 · 30fps · 45 seconds.

This is a visual prototype. It uses drawn SVG stick figures and on-screen text; narration, sound design, and final historical fact-checking should be added before publication. The traditional date for the founding of the Roman Republic is 509 BC; details of the early monarchy are partly legendary.

To run Remotion from Android, use a browser-based development environment such as GitHub Codespaces if available; usage may be billable.
